# 中国大陆 — 录课（VOD）+ 真直播（RTC）实施路线图

**适用产品：** EAP Platform（`eap_platform_agent`）  
**原则：** 仅考虑中国大陆可用、开通快、运维简单；不依赖 Render 海外节点承载音视频。  
**与现有系统关系：** 保留 Phase **L/K** 的 Classroom Display 推送（PPT/PDF/HTML）；本路线在其上增加 **录课点播** 与 **音视频直播 + 可选露脸 + 实时标注**。

**Last updated:** 2026-05-26

---

## 1. 你现在有什么 / 缺什么

| 能力 | 现状 | 本路线目标 |
|------|------|------------|
| 老师推 PPT/PDF 给学生 | ✅ Live Teaching + Display library | 保留，作为「教材区」 |
| 学生同步看资料 | ✅ 长轮询 + `display-file` | 保留；标注改 WebSocket |
| 现场音频 | ❌ | TRTC 音频 |
| 老师露脸（可选） | ❌ | TRTC 摄像头轨，UI 开关 |
| PDF/PPT 上实时画笔 | ❌ | 腾讯云互动白板 TIW 或 自研 Canvas 层 |
| 老师上传录课、学生仅观看 | ❌ | 腾讯云点播 VOD + 播放器防盗链 |
| 学生不能下载录课 | ❌ | HLS 加密流 + 无下载 API + 域名 Referer 防盗链 |

## 2. 推荐技术选型（大陆优先）

| 模块 | 首选 | 备选 | 说明 |
|------|------|------|------|
| **录课存储与转码** | [腾讯云点播 VOD](https://cloud.tencent.com/product/vod) | 阿里云视频点播 | 上传 → 自动转 HLS → 播放器 SDK |
| **直播音视频** | [腾讯云 TRTC](https://cloud.tencent.com/product/trtc) | [声网 Agora](https://www.shengwang.cn/) | 低延迟、国内节点多 |
| **屏幕/课件 + 画笔** | [腾讯云互动白板 TIW](https://cloud.tencent.com/product/tiw) + TRTC | 声网灵动课堂 | PDF/PPT 导入白板，笔画同步 |
| **对象存储** | 腾讯云 COS | 阿里云 OSS | 与 VOD 同源，减少跨云 |
| **Web 站点托管** | 腾讯云 CVM/Lighthouse + CDN | 阿里云 ECS | **录课/直播上线时必须大陆机房** |
| **HTTPS 域名** | 已备案域名 + SSL | — | 海外 Render 仅适合试点，不适合真直播 |

**不推荐作为大陆主方案：** Zoom/Daily/Mux（海外节点、备案与延迟问题）。

## 3. 阶段划分（对应 Tracker Phase N / O）

### Phase N — 录课点播（VOD）

| ID | 任务 | 负责 | 依赖 |
|----|------|------|------|
| N0 | 大陆部署基线：备案域名 + 腾讯云账号 + COS/VOD 开通 | **你** | 营业执照 |
| N1 | 后端：录课元数据表（班级、标题、vod_file_id、可见性、关联任务） | 开发 | N0 |
| N2 | 老师端：上传页（直传 COS 或 VOD 服务端签名上传） | 开发 | N0 |
| N3 | VOD 转码回调 Webhook → 标记「可播放」 | 开发 | N0 |
| N4 | 学生端：仅 Web 播放器（腾讯超级播放器 / TCPlayer），禁右键、无下载按钮 | 开发 | N1–N3 |
| N5 | 播放鉴权：Flask 签发 **短期播放签名**（UserSig 或 VOD 防盗链 Key） | 开发 | N1 |
| N6 | 与日历/任务挂钩：录课作为任务类型或附件 | 开发 | N1 |
| N7 | QA：Chrome/微信内置浏览器、4G/校园网、进度续播 | **你+开发** | N4 |

### Phase O — 真直播（RTC + 可选露脸 + 标注）

| ID | 任务 | 负责 | 依赖 |
|----|------|------|------|
| O0 | 开通 TRTC +（可选）TIW；创建应用、拿到 SDKAppID/Secret | **你** | N0 同账号 |
| O1 | 后端：直播课次表（房间号、班级、是否允许露脸、状态） | 开发 | O0 |
| O2 | 老师开课：创建 TRTC 房间 + 生成 UserSig（teacher） | 开发 | O0 |
| O3 | 学生加入：同房间 audio 订阅；**默认只听音频 + 看 Display** | 开发 | O1 |
| O4 | 老师「露脸」开关：动态 publish/unpublish 摄像头轨 | 开发 | O2 |
| O5 | 保留现有 Display 推送；与 TRTC 同屏 UI（大屏课件、小窗老师可选） | 开发 | 现有 L/K |
| O6a | **方案 A（快）：** TIW 白板，PPT/PDF 导入，笔画经白板同步 | 开发 | O0 TIW |
| O6b | **方案 B（控）：** 自研 Canvas 标注 + WebSocket 广播（与 session_code 绑定） | 开发 | O1 |
| O7 | 延迟与弱网：TRTC 自动重连；标注丢包补偿 | 开发 | O2–O6 |
| O8 | 录制回放（可选）：TRTC 云端录制 → 写入 VOD → 课后当录课 | 开发 | N3, O2 |
| O9 | 合规文案：摄像头/麦克风授权、隐私政策、课堂行为说明 | **你** | — |
| O10 | 试点课 1 节真机验收（老师 1 + 学生 10，大陆 4G） | **你** | 全部 |

**建议顺序：** 先 **N（录课）** 再 **O（直播）**；O6 优先 **方案 A（TIW）**  unless 预算或授权复杂，再退方案 B。

## 4. 你需要额外做的操作（详细清单）

以下由**机构（你方）**完成；开发可在 Cursor 内写对接代码，但**无法代替**云账号与备案。

### 4.1 主体与合规（一次性）

| 步骤 | 做什么 | 产出物 | 预计时间 |
|------|--------|--------|----------|
| 1 | 确认运营主体：**学校自有** 或 **公司**（建议企业/事业单位主体） | 营业执照 / 办学许可证复印件 | — |
| 2 | 准备 **隐私政策**、**用户协议**（含录课、摄像头、未成年人） | 网页链接，可放 `/ui/legal/` | 1–3 天（法务或模板） |
| 3 | 课堂告知：首次直播/录课前学生 **知情同意**（勾选或家长授权，按学校要求） | 文案 + 产品勾选 | 与学校确认 |

### 4.2 域名与备案（大陆 Web 必做）

| 步骤 | 做什么 | 产出物 | 预计时间 |
|------|--------|--------|----------|
| 4 | 购买 **.cn 或 .com 域名**（在腾讯云/阿里云购买最省事） | 域名所有权 | 1 天 |
| 5 | **ICP 备案**（网站备案） | 备案号 | **7–20 个工作日** |
| 6 | 备案通过后配置 **HTTPS**（免费 DV 证书即可） | `https://你的域名/ui/` | 1 天 |
| 7 | （可选）**公安联网备案** | 公安备案号 | 备案后 30 日内 |

> **重要：** 当前 Render 海外地址 `eap-platform-pilot.onrender.com` 可继续作试点；**Phase N/O 正式上线必须迁到大陆服务器 + 已备案域名**，否则 TRTC/VOD 体验差且部分能力受限。

### 4.3 腾讯云开通（录课 + 直播）

登录 [腾讯云控制台](https://console.cloud.tencent.com/)（建议企业实名认证）。

| 步骤 | 开通产品 | 控制台路径 | 你需要交给开发的信息 |
|------|----------|------------|----------------------|
| 8 | 实名认证 | 账号中心 | — |
| 9 | **对象存储 COS** | 对象存储 | `SecretId`、`SecretKey`、Bucket、Region（如 `ap-guangzhou`） |
| 10 | **云点播 VOD** | 云点播 | 子应用 ID、转码模板（HLS 720p）、回调 URL |
| 11 | **实时音视频 TRTC** | TRTC | `SDKAppId`、`SDKSecretKey`（仅放服务器环境变量） |
| 12 | **互动白板 TIW**（若用方案 A） | 互动白板 | TIW 应用 ID、与 TRTC 同账号关联 |
| 13 | **CDN**（可选，学生多时） | CDN | 加速域名（需已备案） |
| 14 | 购买 **资源包** 或按量计费 | 费用中心 | 录课试点约 ¥几百/月；直播按分钟计费 |

**密钥安全（你必须遵守）：**

- `SecretKey` / `SDKSecretKey` **只放在服务器环境变量**（如 `.env`、腾讯云 SSM），**不要**写进 Git、不要发给微信群。
- 开发完成后你方在服务器上配置，例如：
  - `TENCENT_SECRET_ID`
  - `TENCENT_SECRET_KEY`
  - `TRTC_SDK_APP_ID`
  - `TRTC_SDK_SECRET_KEY`
  - `VOD_SUB_APP_ID`（若使用）

### 4.4 VOD 防盗链（录课不可轻易下载）

在腾讯云 VOD 控制台配置（开发会告诉你具体项）：

| 配置项 | 建议 |
|--------|------|
| 播放域名 | 使用 VOD 自带或 CDN 域名（已备案） |
| **Key 防盗链** | 开启；由 Flask 按用户+班级签发短期 URL |
| **试看/水印**（可选） | 学校 Logo 或学生学号水印 |
| 禁止 MP4 直链 | 仅 HLS（`.m3u8`）给播放器 |

学生端：**不提供「下载」按钮**；后端**不提供**原始文件下载 API。

### 4.5 TRTC 直播课（真直播）

| 步骤 | 做什么 |
|------|--------|
| 15 | TRTC 控制台创建应用 → 记录 `SDKAppId` |
| 16 | 查看 **音视频时长套餐**；试点可先按量 |
| 17 | 浏览器授课：无需上架应用商店；**微信内打开**需域名备案 + HTTPS |
| 18 | 老师电脑：Chrome 最新版；耳机+麦克风；露脸需摄像头权限 |
| 19 | 学校网络：若防火墙拦截 UDP，联系网管放行 TRTC 域名（腾讯云文档有端口列表） |

### 4.6 从 Render 迁到大陆（N/O 上线时）

| 步骤 | 做什么 |
|------|--------|
| 20 | 购买 **轻量应用服务器** 或 CVM（推荐华南/华东，离学校近） |
| 21 | Docker 部署现有 Flask（与 Render 相同镜像逻辑） |
| 22 | SQLite 试点可继续；正式建议 **腾讯云 MySQL** |
| 23 | 上传目录、VOD 分离；大文件不进 Git |
| 24 | 环境变量迁移 + 域名解析 + SSL |
| 25 | 试点账号改密；全链路复测 WEB_LAUNCH_CHECKLIST |

### 4.7 费用粗算（供预算）

| 项目 | 试点班级（约 30 人） | 说明 |
|------|----------------------|------|
| VOD 存储+转码 | ¥50–300/月 | 视录课小时数 |
| TRTC 音频课 45 分钟 × 30 人 | 按量，约 ¥数十–百元/节 | 以控制台计算器为准 |
| TRTC 露脸视频 | 高于纯音频 | 老师开摄像头即计费略增 |
| TIW 白板 | 按白板时长 | 方案 A 才有 |
| 服务器+CDN | ¥100–500/月 | 轻量+流量 |

## 7. 你确认「我懂了吗」— 对齐总结

你的目标可以概括为：

1. **录课：** 老师上传，学生在 EAP **只能在线看**，不提供下载。  
2. **直播：** 老师现场上课，学生**实时**看到推送的 PPT/PDF 等，并能在文件上**画重点**；有**现场音频**；老师可选**是否露脸**，默认只播课堂 Display 区域。  
3. **地域：** 全套以**中国大陆**好用为准，接受腾讯云为主、站点迁到大陆备案域名。  
4. **分工：** 开发写对接与页面；**你方**负责备案、云账号、密钥、费用、隐私文案与学校合规。
